# Glossary · 용어표

Key terms used in both language versions. Both docs must use the terms in this table.
두 언어 문서에서 함께 쓰는 핵심 용어입니다. 문서를 쓸 때 이 표의 용어를 따릅니다.

| Term | English | 한국어 |
|---|---|---|
| GPC | grapheme–phoneme correspondence | 철자-소리 대응 |
| Gr | grapheme | 글자 (철자 단위) |
| Ph | phoneme | 소리 (음소) |
| Token | surface form as written in the passage | 지문에 쓰인 낱말 형태 |
| Token-a | sound key: lowercase Token + sound number (`read-2`) | 소리 키: 소문자 Token + 소리 번호 (`read-2`) |
| a# | sound number within a Token | Token 안의 소리 번호 |
| p.Token | part of speech + Token (`v.read`) | 품사 + Token (`v.read`) |
| Lemma | dictionary form | 원형 |
| s# | sense number within a lemma | 원형 안의 의미 번호 |
| p.Lemma-s | sense key: POS + lemma + sense number (`v.read-1`) | 뜻 키: 품사 + 원형 + 의미 번호 (`v.read-1`) |
| Aud_ID | fixed recording ID per pronunciation (`A00001`) | 발음별 고정 녹음 번호 (`A00001`) |
| sound registry | frozen record of every assigned `a#` | 소리 번호 고정 대장 |
| context key | `(Line_ID, Seq)`, one word occurrence | 문맥 키 `(Line_ID, Seq)`, 낱말 출현 하나 |
| decision file | human judgments keyed by context | 문맥 키로 저장한 사람 판정 파일 |
| default sense | sense used when no context decision exists | 대표값 (문맥 판정이 없을 때 쓰는 뜻) |
| main target | what the lesson's core activity teaches | 메인 타깃 |
| additional target | targets reinforced elsewhere in the lesson | 추가 타깃 |
| Environment | where the GPC must occur (initial, medial, final) | 위치 조건 (어두, 어중, 어말) |
| Morph | word-internal pieces: endings, affixes, contractions | 형태 요소: 어미, 접사, 축약 |
| Lexical | whole-word targets: homophones, compounds, synonyms | 어휘 관계: 동음어, 합성어, 유의어 |
| HFW | high-frequency word | 고빈도어 |
| decodability | share of words readable with GPCs taught so far | 해독 가능성 (지금까지 배운 GPC로 읽을 수 있는 낱말 비율) |
