# phonics-annotation-toolkit

[English](README.md) | **한국어**

파닉스 교재 지문을 낱말 단위로 주석(annotation)하는 파이프라인입니다.
낱말마다 **소리(발음·철자-소리 대응)** 와 **뜻(품사·의미 번호)** 을 따로 관리하고,
그 결과로 레슨 타깃 판정과 **음성·이미지 에셋 목록**을 만듭니다.

> 이 저장소는 실무에서 설계·운영한 코퍼스 구축 경험을 바탕으로 **처음부터 새로 작성한** 데모입니다.
> 실제 교재 문장, 회사 코드, 회사 데이터는 들어 있지 않습니다. 예시 문장은 모두 직접 지은 것입니다.

## 배경

파닉스 교재는 "이번 레슨에서 배우는 철자-소리 규칙"을 중심으로 짜여 있습니다.
교재 콘텐츠를 디지털화하려면 지문 속 낱말 하나하나에 대해 다음을 알아야 합니다.

- 이 낱말이 **어떻게 소리 나는가**: 철자-소리 대응(GPC), 음절, 녹음 파일
- 이 낱말이 **무엇을 뜻하는가**: 품사, 원형, 의미 번호, 삽화
- 이 낱말이 **이 레슨의 타깃인가**: 레슨이 가르치는 GPC·형태·어휘 관계에 맞는가

실무에서는 두 교재 시리즈, 세 개 레벨, 수만 건의 낱말 출현을 이 방식으로 주석했습니다.
이 저장소는 그때 세운 데이터 모델과 처리 단계를 작은 예시 데이터로 재현합니다.

## 핵심 설계: 소리 축과 뜻 축

낱말의 소리와 뜻은 일대일로 대응하지 않습니다.

| 예 | 철자 | 소리 | 뜻 |
|---|---|---|---|
| `read` (읽다 / 읽었다) | 1 | 2 (/rid/, /rɛd/) | 1 |
| `bow` (리본 / 인사 / 절하다) | 1 | 2 (/boʊ/, /baʊ/) | 3 |
| `to` · `too` · `two` | 3 | 1 (/tu/) | 3 |

그래서 Word 행 하나를 두 축의 키로 나눠 관리합니다.

```
                  Word (지문 속 낱말 출현 하나)
                 /                          \
   소리 축 — Token-a                       뜻 축 — p.Lemma-s
   read-1, read-2, bow-1 ...               v.read-1, n.bow-2 ...
        │                                        │
   GPC 분해 (글자·소리·음절·위치)              뜻 사전
        │                                        │
   Aud_ID — 발음 하나 = 녹음 하나              이미지 단위 — 뜻 하나(+형태) = 이미지 하나
```

자세한 내용은 [데이터 모델](docs/ko/data_model.md)에 있습니다. 용어는 [용어표](docs/glossary.md)를 참고하세요.

## 처리 단계

| 단계 | 하는 일 | 상태 |
|---|---|---|
| 1 | Line_ID 부여 | 완료 |
| 2 | 토큰화, 구(phrase) 병합 | 완료 |
| 3 | 품사·원형·뜻 판정 (문맥 결정 파일 + 대표값) | 완료 |
| 4 | GPC 분해 | 완료 |
| 4-b | 소리 번호(`a#`) 부여, 번호 고정 대장 | 완료 |
| 5 | 레슨 타깃 판정 (메인·추가) | 완료 |
| 6~8 | Word_ID, 고빈도어, 굴절형 표시 | 완료 |
| 9 | 뜻 사전·이미지·음성 에셋 목록 생성 | 완료 |

단계별 입력·규칙·명령은 [처리 단계](docs/ko/workflow.md)에 있습니다.

## 분석: 해독 가능성

레슨마다 "지금까지 배운 GPC만으로 지문 낱말의 몇 %를 읽을 수 있는가"를 재고, 읽지 못하게 막는 GPC를 찾습니다.
예시 커리큘럼에서는 sh 레슨의 해독 가능 비율이 13%에 그쳤는데, 짧은 i(`ship`, `fish`, `dish`)를 아직 가르치지 않은 것이 원인이었습니다.
레슨 순서의 빈틈을 데이터로 찾아내는 예입니다. 자세한 내용은 [해독 가능성 분석](docs/ko/decodability.md)에 있습니다.

```
└── analysis/              # 분석 가정 (기초 GPC 목록)
```

## 실행

```bash
python -m venv venv
source venv/bin/activate
pip install -e ".[dev]"
python -m pytest

# 전체 단계 실행: 요약 보기 → 결과 파일 쓰기 (out/)
python -m phonics_toolkit
python -m phonics_toolkit --write

# 해독 가능성 분석
python -m phonics_toolkit.decodability
```
